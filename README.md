# CloudVault

Store your files and media, write notes, and manage everything in one place.

**Live:** https://cloud-vault-server.vercel.app

## Features

- Upload, download and organise files
- Media library for images, videos, audio and documents
- Notes with a clean editor
- Light and dark mode
- Works on mobile and desktop
- Storage limit of 500 MB per user
- Admin can view all users and manage their files and notes

## Built With

React, TypeScript, Vite, Tailwind CSS, Framer Motion

## Getting Started

```bash
git clone https://github.com/<your-username>/Cloud-Vault.git
cd Cloud-Vault
npm install
npm run dev
```

## Environment

Create a `.env` file:

```
VITE_API_URL=https://cloud-vault-backend-fawn.vercel.app/api
```

## Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start the development server |
| `npm run build` | Create a production build |
| `npm run preview` | Preview the production build |
